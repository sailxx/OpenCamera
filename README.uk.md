# Open Camera


**Нативний верстак Linux для камер Video4Linux.**

Виберіть веб-камеру, перегляньте її попередній перегляд у реальному часі, виберіть режим зйомки та налаштуйте елементи керування, доступні драйвером камери.

<summary><b>Детальніше про особливості</b></summary>

- **Фотоапарати.** Виберіть пристрій V4L2 і повторіть сканування після підключення або відключення камери.
- **Попередній перегляд.** Запустіть і зупиніть локальний потік і подивіться швидкість захоплення, виміряну в джерелі. Якщо доступно, програма малює рамки за допомогою раковини GStreamer GTK 4. Він також підтримує обмежену резервну текстуру GTK.
- **Режими захоплення.** Використовуйте автоматичне узгодження або виберіть рекламоване поєднання роздільної здатності, формату пікселів і частоти кадрів. Змінюйте режими між сеансами попереднього перегляду.
- **Апаратні елементи керування.** Відредагуйте цифрові елементи, перемикачі та елементи керування меню, які повідомляє водій. Зміни надсилаються драйверу, коли ви їх вносите.
- **Діагностика та зовнішній вигляд.** Перевірте доступ до пристрою, відсутні залежності та помилки попереднього перегляду. Налаштування пропонують системний, світлий і темний вигляд.

## Швидкий старт

1. Підключіть веб-камеру та виберіть її **пристрій**. Скористайтеся кнопкою оновлення, якщо її було підключено після відкриття програми.
2. Open Camera вибирає 60 FPS, коли камера повідомляє про це, або 59.94 FPS, коли це єдиний режим близько 60. Виберіть **Автоматичний** дозволити водієві узгодити або вибрати одну з повідомлених комбінацій.
3. Натисніть **Почати попередній перегляд**. Зчитування FPS вимірює кадри, що надходять від джерела. Вона може відрізнятися від запитаної швидкості та не вимірює оновлення монітора.
4. Налаштуйте елементи керування, які відкриває ваш водій під час попереднього перегляду. Зміна роздільної здатності, формату чи частоти кадрів автоматично перезапускає попередній перегляд.

Open Camera надає локальний робочий стіл для налаштування та тестування веб-камери. Версія 0.2.4 не має запису, обробки ефектів або виведення віртуальної камери.

<h2 id="run-on-linux">📦 Запуск на Linux</h2>

Завантажити Open Camera **v0.2.4** від [Релізи GitHub](https://github.com/sailxx/OpenCamera/releases/tag/v0.2.4).

| Завантажити | Встановити або запустити |
| --- | --- |
| [DEB](https://github.com/sailxx/OpenCamera/releases/download/v0.2.4/open-camera_0.2.4_all.deb) | `sudo apt install ./open-camera_0.2.4_all.deb` на Ubuntu 24.04 |
| [RPM](https://github.com/sailxx/OpenCamera/releases/download/v0.2.4/open-camera-0.2.4-1.fc44.noarch.rpm) | `sudo dnf install ./open-camera-0.2.4-1.fc44.noarch.rpm` на Fedora 44 |
| [AppImage](https://github.com/sailxx/OpenCamera/releases/download/v0.2.4/OpenCamera-0.2.4-x86_64.AppImage) | `chmod +x OpenCamera-0.2.4-x86_64.AppImage` потім `./OpenCamera-0.2.4-x86_64.AppImage` на x86_64 Linux з glibc 2.39 або новішим |

Запустіть установку DEB або RPM із панелі запуску на робочому столі або за допомогою `open-camera`. Якщо FUSE недоступний, запустіть AppImage за допомогою `./OpenCamera-0.2.4-x86_64.AppImage --appimage-extract-and-run`.

Щоб перевірити завантаження, збережіть [SHA256SUMS](https://github.com/sailxx/OpenCamera/releases/download/v0.2.4/SHA256SUMS) поруч із пакетом і біжи `sha256sum -c --ignore-missing SHA256SUMS` з цього каталогу.

Робочий процес випуску встановив або запустив усі три пакети та перевірив попередній перегляд за допомогою синтетичного джерела. Сумісність фізичної веб-камери все ще потребує перевірки.

### Запустити з джерела

Використовуйте робочий стіл Linux з Python 3.10 +, GTK 4.8 +, libadwaita 1.4 + і GStreamer 1.20 +. Запустіть із папки сховища системний Python, щоб він міг знайти прив’язки PyGObject дистрибутива.

<details open>
<summary><b>Ubuntu 24.04 і новіші</b></summary>

```sh
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 \
  gir1.2-gstreamer-1.0 gir1.2-gst-plugins-base-1.0 \
  gstreamer1.0-plugins-base gstreamer1.0-plugins-good v4l-utils
python3 -m open_camera
```

</details>

<details>
<summary><b>Fedora</b></summary>

```sh
sudo dnf install python3-gobject gtk4 libadwaita gstreamer1 \
  gstreamer1-plugins-base gstreamer1-plugins-good v4l-utils
python3 -m open_camera
```

</details>

<details>
<summary><b>Тест без фізичної камери</b></summary>

```sh
python3 -m open_camera --test-source
```

Для встановлення DEB або RPM використовуйте `open-camera --test-source`. Виберіть **Тестовий шаблон GStreamer**, виберіть 30, 60 або 120 FPS при 1280 × 720 і натисніть **Почати попередній перегляд**. Ці показники описують джерело тесту. Режими фізичного пристрою залежать від камери та драйвера.

</details>

### Усунення несправностей

| Симптом | Що перевірити |
| --- | --- |
| Камера відсутня | Повторно підключіть його, оновіть список пристроїв і перевірте **діагностика** для відсутніх компонентів або дозволів пристрою. |
| Попередній перегляд не запускається | Закрийте програми за допомогою камери, спробуйте **Автоматичний**, потім перевірте **діагностика** для помилки трубопроводу. Для закодованих режимів може знадобитися встановлений декодер. |
| Джерело FPS нижче обраної швидкості | Перевірте доступні тарифи для цієї роздільної здатності та формату. Спробуйте нижчу роздільну здатність або інший порт USB і порівняйте вимірювання. |

Повідомляючи про проблему, укажіть розповсюдження, модель камери, вибраний режим зйомки та відповідний текст **діагностика**.

<h2 id="design">Дизайн</h2>
