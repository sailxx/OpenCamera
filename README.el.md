# Open Camera


**Ένας εγγενής πάγκος εργασίας Linux για κάμερες Video4Linux.**

Επιλέξτε μια κάμερα web, δείτε τη ζωντανή προεπισκόπηση της, επιλέξτε μια λειτουργία λήψης και προσαρμόστε τα χειριστήρια που εκτίθενται από το πρόγραμμα οδήγησης της κάμερας.

- **Κάμερες.** Επιλέξτε μια συσκευή V4L2 και σαρώστε ξανά αφού συνδέσετε ή αποσυνδέσετε μια κάμερα.

- **Διαγνωστικά και εμφάνιση.** Ελέγξτε την πρόσβαση της συσκευής, τις εξαρτήσεις που λείπουν και τα σφάλματα προεπισκόπησης. Οι Ρυθμίσεις προσφέρουν σύστημα, φωτεινή και σκοτεινή εμφάνιση.

## Γρήγορη εκκίνηση

1. Συνδέστε μια κάμερα web και επιλέξτε την **Συσκευή**. Χρησιμοποιήστε το κουμπί ανανέωσης εάν ήταν συνδεδεμένο μετά το άνοιγμα της εφαρμογής.
2. Το Open Camera επιλέγει 60 FPS όταν το αναφέρει η κάμερα ή 59.94 FPS όταν αυτή είναι η μόνη λειτουργία κοντά στα 60. Επιλέγω **Αυτόματο** για να επιτρέψετε στον οδηγό να διαπραγματευτεί ή να επιλέξει έναν από τους αναφερόμενους συνδυασμούς.
3. Κλικ **Έναρξη προεπισκόπησης**. Η ένδειξη FPS μετρά τα καρέ που φτάνουν από την πηγή. Μπορεί να διαφέρει από τον απαιτούμενο ρυθμό και δεν μετρά την ανανέωση της οθόνης.
4. Προσαρμόστε τα χειριστήρια που εκθέτει το πρόγραμμα οδήγησης κατά την παρακολούθηση της προεπισκόπησης. Η αλλαγή της ανάλυσης, της μορφής ή του ρυθμού καρέ επανεκκινεί αυτόματα την προεπισκόπηση.

Το Open Camera παρέχει έναν τοπικό πάγκο εργασίας για τη διαμόρφωση και τη δοκιμή μιας κάμερας web. Η έκδοση 0.2.4 δεν διαθέτει εγγραφή, επεξεργασία εφέ ή έξοδο εικονικής κάμερας.

<h2 id="run-on-linux">📦 Εκτελέστε σε Linux</h2>

Κατεβάστε το Open Camera **v0.2.4** από [Εκδόσεις GitHub](https://github.com/sailxx/OpenCamera/releases/tag/v0.2.4).

| Λήψη | Εγκατάσταση ή εκκίνηση |
| --- | --- |
| [DEB](https://github.com/sailxx/OpenCamera/releases/download/v0.2.4/open-camera_0.2.4_all.deb) | `sudo apt install ./open-camera_0.2.4_all.deb` στο Ubuntu 24.04 |
| [RPM](https://github.com/sailxx/OpenCamera/releases/download/v0.2.4/open-camera-0.2.4-1.fc44.noarch.rpm) | `sudo dnf install ./open-camera-0.2.4-1.fc44.noarch.rpm` στο Fedora 44 |
| [AppImage](https://github.com/sailxx/OpenCamera/releases/download/v0.2.4/OpenCamera-0.2.4-x86_64.AppImage) | `chmod +x OpenCamera-0.2.4-x86_64.AppImage` τότε `./OpenCamera-0.2.4-x86_64.AppImage` σε x86_64 Linux με glibc 2.39 ή νεότερο |

Ξεκινήστε την εγκατάσταση DEB ή RPM από τον εκκινητή επιφάνειας εργασίας ή με `open-camera`. Εάν το FUSE δεν είναι διαθέσιμο, εκκινήστε το AppImage με `./OpenCamera-0.2.4-x86_64.AppImage --appimage-extract-and-run`.

Για να ελέγξετε τη λήψη, αποθηκεύστε [SHA256SUMS](https://github.com/sailxx/OpenCamera/releases/download/v0.2.4/SHA256SUMS) δίπλα στο πακέτο και τρέξτε `sha256sum -c --ignore-missing SHA256SUMS` από αυτόν τον κατάλογο.

Η ροή εργασιών έκδοσης εγκατέστησε ή ξεκίνησε και τα τρία πακέτα και έλεγξε τη ζωντανή προεπισκόπηση χρησιμοποιώντας μια συνθετική πηγή. Η συμβατότητα φυσικής κάμερας web εξακολουθεί να χρειάζεται επικύρωση.

### Εκτέλεση από την πηγή

Χρησιμοποιήστε έναν επιτραπέζιο υπολογιστή Linux με Python 3.10 +, GTK 4.8 +, libadwaita 1.4 + και GStreamer 1.20 +. Εκτελέστε από το φάκελο αποθετηρίου με το σύστημα Python ώστε να μπορεί να βρει τις δεσμεύσεις PyGObject της διανομής.

<details open>
<summary><b>Ubuntu 24.04 και νεότερα</b></summary>

```sh
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 \
  gir1.2-gstreamer-1.0 gir1.2-gst-plugins-base-1.0 \
  gstreamer1.0-plugins-base gstreamer1.0-plugins-good v4l-utils
python3 -m open_camera
```

</details>

<details>
<summary><b>Μαλακό καπέλλο</b></summary>

```sh
sudo dnf install python3-gobject gtk4 libadwaita gstreamer1 \
  gstreamer1-plugins-base gstreamer1-plugins-good v4l-utils
python3 -m open_camera
```

</details>

<details>
<summary><b>Δοκιμή χωρίς φυσική κάμερα</b></summary>

```sh
python3 -m open_camera --test-source
```

Για εγκατάσταση DEB ή RPM χρησιμοποιήστε `open-camera --test-source`. Επιλέγω **Μοτίβο δοκιμής GStreamer**, επιλέξτε 30, 60 ή 120 FPS στα 1280 × 720 και κάντε κλικ **Έναρξη προεπισκόπησης**. Αυτά τα ποσοστά περιγράφουν την πηγή δοκιμής. Οι λειτουργίες φυσικής συσκευής εξαρτώνται από την κάμερα και το πρόγραμμα οδήγησης.

</details>

### Αντιμετώπιση προβλημάτων

| Σύμπτωμα | Τι να ελέγξετε |
| --- | --- |
| Η κάμερα λείπει | Συνδέστε το ξανά, ανανεώστε τη λίστα συσκευών και ελέγξτε **Διαγνωστικά** για στοιχεία που λείπουν ή δικαιώματα συσκευής. |
| Η προεπισκόπηση αποτυγχάνει να ξεκινήσει | Κλείστε τις εφαρμογές χρησιμοποιώντας την κάμερα, δοκιμάστε **Αυτόματο**, στη συνέχεια ελέγξτε **Διαγνωστικά** για το σφάλμα του αγωγού. Οι κωδικοποιημένες λειτουργίες ενδέχεται να απαιτούν εγκατεστημένο αποκωδικοποιητή. |
| Η πηγή FPS είναι κάτω από την επιλεγμένη τιμή | Ελέγξτε τις διαθέσιμες τιμές σε αυτήν την ανάλυση και τη μορφή. Δοκιμάστε μια χαμηλότερη ανάλυση ή μια διαφορετική θύρα USB και συγκρίνετε τη μέτρηση. |

Όταν αναφέρετε ένα πρόβλημα, συμπεριλάβετε τη διανομή, το μοντέλο κάμερας, την επιλεγμένη λειτουργία λήψης και το σχετικό κείμενο από **Διαγνωστικά**.

<h2 id="design">Σχέδιο</h2>
